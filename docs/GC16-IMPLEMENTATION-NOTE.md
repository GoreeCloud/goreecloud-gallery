# gc.16 implementation note

`gc.16` is a presentation-only follow-up to the gc.15 representative-device review. It changes the root ScrollView geometry of sorting, grouping, and media-filter dialogs from full-height to content-driven height and leaves overflow scrolling enabled. It increments Android `versionCode` to `10016` while preserving semantic version `1.0.0`.

No new dependency, network permission, remote asset, analytics, tracking, advertising, or behavioral change is introduced.
